每日任务产出・存放位置规范（极简版，直接照做）

一、olist 核心项目（你每天 90% 内容放这）
olist/sql/ddl/
建表语句、SCHEMA、主键、外键、CHECK 约束
字段注释、索引、一键建库 SQL

olist/sql/quality/
NULL 统计、重复主键检查
异常金额、非法状态、时间逻辑校验
数据质量探查脚本

olist/sql/analysis/
分组统计、支付方式分析、订单状态分析
TOP 商品 / 商家、复购率、RFM
物流时效、环比、移动平均、用户分层

olist/sql/mart/
订单宽表、用户宽表、商品宽表、商家宽表
多表关联大宽表、指标汇总表

olist/raw_data/
原始 CSV、样例数据（不上传 GitHub）

olist/notes/
每日学习笔记、踩坑记录
实验总结、脏数据处理 SOP
业务简报草稿

olist/scripts/

一键执行 SQL 脚本
批量导入、初始化工具脚本


二、ETL / Python 相关
etl/pg_load/
PostgreSQL 数据导入 Python 脚本
CSV 读取、清洗、入库

etl/quality/
Python 自动化数据质量检查
缺失值、异常值、重复值检测

etl/features/
宽表构建、RFM 计算、用户分群

etl/utils/
数据库连接工具 db.py
通用函数、配置、日志工具
